# Saran Privacy Policy — GitHub Pages

## Before publishing

1. In `index.html`, replace **[SUPPORT_EMAIL]** (three instances) with a working support address.
2. Replace **[PLAY_CONSOLE_DEVELOPER_NAME]** with the exact developer/publisher name in Play Console.
3. Carefully review the policy against the release build: types of personal data, Firebase Analytics, Turso, any Google sign-in or maps providers, location permissions, background location, data retention and account deletion.
4. Add an actual account deletion URL and realistic timelines to the Data retention and deletion section. Ensure the corresponding deletion functionality actually works.
5. Check children's age audience, support workflows and third-party data sharing.
6. Update the effective date if needed. Your Google Play Data safety answers must match the actual practices and this page.

This is a draft legal policy and must be reviewed for accuracy before release.

## Publish using GitHub Pages

1. Create a public GitHub repository named `saran-privacy` (any name works).
2. Upload `index.html` and `saran-logo.webp` to the **root** of the repository. Do not upload only the zip file.
3. Go to **Settings → Pages → Build and deployment**.
4. Select **Deploy from a branch**; choose `main` and `/(root)`; press **Save**.
5. The public URL will typically be `https://YOUR-USERNAME.github.io/saran-privacy/`.
6. Add this URL to **Play Console → App content → Privacy policy** and link it from Saran's Settings screen.

The website is static, mobile responsive, and does not itself set analytics cookies or require a server.
